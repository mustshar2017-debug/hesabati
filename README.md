# حساباتي – المستشار ود كنانة

تطبيق عربي لإدارة الرصيد والتحويلات وشحن الهواتف والمصروفات والتقارير.

## الملفات
- `index.html`: تشغيل التطبيق.
- `manifest.webmanifest`: بيانات تثبيت التطبيق.
- `service-worker.js`: التخزين المؤقت والعمل دون اتصال بعد أول تحميل.
- `icons/icon.svg`: الأيقونة المعتمدة بألوان الأخضر والذهبي.

## النشر
فعّل GitHub Pages من Settings → Pages واختر GitHub Actions أو النشر من الفرع main ومجلد الجذر.

## تنبيه البيانات
البيانات تحفظ محلياً في المتصفح على الجهاز نفسه. استخدم النسخ الاحتياطي بانتظام. قفل PIN واجهة حماية محلية وليس تشفيراً للبيانات، ولا توجد استعادة تلقائية لكلمة السر.
